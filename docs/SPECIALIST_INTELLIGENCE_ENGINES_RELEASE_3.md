# Specialist Intelligence Engines — Release 3

Adds deterministic, review-first analytic engines for all five roles. Inputs are supplied by the application or analyst. No network requests, new provider credentials, X API access or live feed integrations are added.

- **Defence & Information Warfare:** six-lane coverage, collection gaps, claim decomposition, evidence for/against and alternative hypotheses. Strategic public-source scope only.
- **Corporate Risk:** filing/event chronology, identifier anchoring checks, candidate identity review, sanctions-match review and ownership disclosure caveats.
- **Supply Chain:** supplier concentration (HHI), top-five share, route exposure, disruption register and data-quality warnings.
- **Geopolitical:** event chronology, disputed/unverified status, competing claims and indicator review; no causal inference.
- **Strategic Foresight:** drivers, scenario probability-sum validation, signposts and forecast archive coverage.

These are pure module functions; callers must preserve source provenance and evidence IDs. Passing deterministic tests is not proof of intelligence accuracy or live coverage. Scores remain acceptance targets until analyst-facing workflows, connected data, end-to-end tests and analyst acceptance are complete.
